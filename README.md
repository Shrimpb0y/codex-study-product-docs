# Codex Study

Codex 答题卡式教学 UI 与交互扩展的需求文档，首个应用场景为 `skill-study`。

每题包含题目层、用户作答层和初始空白的模型输出层。用户点击审批后，系统汇总答案并依据材料生成批改；点击跳过则生成教学要点。含义不明确时，使用局部澄清询问框补充信息。
